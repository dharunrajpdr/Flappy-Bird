# 🐦 Flappy Bird

A simple Flappy Bird-style game built with **React + Vite + HTML Canvas**.

## 🎮 Features

- Click / tap to flap
- Spacebar or Arrow Up controls
- Moving pipes with collision detection
- Score and best-score tracking
- Restart after game over
- Responsive UI for desktop and mobile

## 🚀 Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- HTML Canvas
- CSS

## 🎯 Controls

| Action | Control |
| --- | --- |
| Flap | Click / Tap |
| Flap | Space |
| Flap | Arrow Up |
| Restart | Click / Tap after Game Over |

## 📁 Main Files

- `src/App.jsx` — game logic, animation, collision detection and scoring
- `src/index.css` — responsive interface styling
- `src/main.jsx` — React entry point
